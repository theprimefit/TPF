Hindivine Leads is installed

Your WhatsApp lead agent now runs inside Chrome. No server, address or password needed.

  1. Open WhatsApp Web and log in by scanning its QR code with the business phone.
  2. Keep that tab open (right-click the tab → Pin). The agent replies to new messages there.
  3. Click the Hindivine Leads icon in Chrome's toolbar to see leads, alerts and the auto-reply switch. (Pin it from the puzzle-piece menu.)

Good to know

  • The agent only answers numbers that aren't saved in your phone, so friends and family don't get bot replies. You can change this in Settings.
  • While you're using the WhatsApp Web tab yourself, the agent only handles the chat you have open and never switches chats on you.
  • If you type a reply yourself, the agent pauses on that chat. Resume it from the popup.
  • Chrome must stay open and the computer awake for replies and follow-ups to go out.
  • Automating WhatsApp Web is unofficial: WhatsApp may restrict numbers it sees as automated. The agent replies only to people who message first, at a human pace.
