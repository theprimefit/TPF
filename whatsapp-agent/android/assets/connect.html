Where do I find the address?

  • On the computer running the agent, open the Setup page. The public link is shown at the top, e.g. https://hindivine.ngrok-free.app.
  • On Render it looks like https://hindivine-agent.onrender.com.
  • On the same office Wi-Fi you can use the computer's address, e.g. http://192.168.1.20:3000.

After connecting, log in with the dashboard password.
